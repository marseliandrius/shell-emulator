# Эмулятор оболочки, вариант 25
## Общее описание.
Практическая работа по конфигурационному управлению. Вариант 25, язык Go.

Проект: консольный эмулятор оболочки UNIX-подобной ОС.

Реализованы первые три этапа: консольный прототип с циклом REPL, конфигурация запуска и загрузка виртуальной файловой системы из CSV.


## Функциональность и настройки.
Подготовлена структура проекта.

Реализованы возможности:

Этап 1:
- приглашение к вводу формируется на основе имени текущего пользователя и имени компьютера, полученных из ОС;
- разбор одинарных и двойных кавычек, включая аргументы с пробелами и пустые аргументы;
- заглушки ls и cd, выводящие имя команды и аргументы;
- exit без аргументов и завершение при конце ввода;
- обработка пустого ввода, незакрытых кавычек, неизвестных команд и аргументов у exit.

Этап 2:
- параметры запуска для указания путей к VFS и стартовому скрипту;
- отладочный вывод значений параметров при запуске;
- выполнение стартового скрипта с отображением команд и результатов;
- остановка стартового скрипта при первой ошибке или команде exit.

Этап 3:
- загрузка виртуальной файловой системы из CSV-файла в память;
- декодирование содержимого файлов из Base64, включая двоичные данные;
- представление вложенных файлов и каталогов с помощью абсолютных путей;
- проверка формата CSV, типов элементов, уникальности путей и наличия родительских каталогов;
- сообщения об ошибках при отсутствии файла VFS или неверном формате данных;
- вывод количества загруженных элементов VFS;
- тестирование минимальной VFS, VFS с несколькими файлами и VFS с вложенными каталогами.

Описание функций:
- main: разбирает параметры, загружает VFS и выбирает режим запуска;
- makePrompt: формирует приглашение к вводу из имени пользователя и имени компьютера;
- parseConfig: получает значения параметров запуска;
- runREPL: читает ввод, вызывает парсер и обработчик команд;
- runScript: выполняет команды файла и останавливается при первой ошибке или exit;
- parser.Parse: разбирает строку на слова с учётом кавычек;
- commands.Execute: выполняет заглушки команд и обрабатывает выход;
- vfs.Load: читает CSV-файл и создаёт виртуальную файловую систему в памяти;
- vfs.parseRecords: проверяет заголовок CSV, собирает элементы и проверяет структуру VFS;
- vfs.parseRecord: преобразует запись CSV в элемент VFS и декодирует содержимое файла;
- vfs.validatePath: проверяет корректность абсолютного пути;
- vfs.validateTree: проверяет корневой каталог и родительские каталоги элементов;
- TestParse: проверяет разбор аргументов и ошибки кавычек;
- TestLoadValid: проверяет загрузку корректных VFS и содержимое файлов;
- TestLoadInvalid: проверяет отклонение некорректных данных VFS;
- TestLoadMissing: проверяет ошибку при отсутствии файла VFS;
- TestVFSMemory: проверяет загрузку двоичных данных и неизменность исходного CSV при изменениях VFS в памяти;
- writeVFSFixture: создаёт временный CSV-файл для теста;
- requireVFSFile: проверяет наличие файла в VFS и возвращает соответствующий элемент.

Параметры запуска:

| Параметр | Назначение | Значение по умолчанию |
|---|---|---|
| `-vfs` | Путь к CSV-файлу виртуальной файловой системы | `data/vfs.csv` |
| `-script` | Путь к стартовому скрипту | Пустая строка |

При запуске программа выводит значения обоих параметров.

Перед выполнением команд программа загружает VFS и выводит количество её элементов.
При ошибке загрузки выводится сообщение, и программа завершается с ненулевым кодом.

CSV-файл должен начинаться с заголовка `path,type,content`.
Каждая следующая запись описывает один элемент:
- `path` — абсолютный путь внутри VFS;
- `type` — `directory` для каталога или `file` для файла;
- `content` — содержимое файла в Base64; для каталога поле должно быть пустым.

Корневой каталог `/` обязателен. Пути должны быть уникальными и не содержать
избыточных разделителей или компонентов `.` и `..`.
Родительский каталог каждого вложенного элемента должен присутствовать в CSV.

VFS хранится в памяти. Её элементы не распаковываются на диск,
а исходный CSV-файл не изменяется.

Подготовлены три варианта VFS:
- `data/minimal.csv` — только корневой каталог, 1 элемент;
- `data/vfs.csv` — два файла и два каталога, включая корневой, 4 элемента;
- `data/nested.csv` — 7 элементов с вложенными каталогами `/home/user/docs`.

Если путь к стартовому скрипту пуст, запускается интерактивный режим.
Если путь указан, программа выполняет команды из файла.

Стартовый скрипт содержит одну команду эмулятора на строку.
Пустые строки пропускаются.
Команды отображаются вместе с приглашением к вводу, затем выводятся результаты.
Выполнение завершается при конце файла, команде exit или первой ошибке.
При ошибке выводится сообщение, и программа завершается с ненулевым кодом.

Относительные пути отсчитываются от текущей рабочей папки.
Скрипт run.bat запускает эмулятор из корня репозитория и передаёт ему параметры.

## Сборка, запуск и тестирование.
Для запуска run.bat необходимы установленные Go и Windows.

Команды выполняются из корня репозитория.

**Сборка:** `go build -o shell-emulator.exe ./src`

**Запуск собранной программы:** `.\shell-emulator.exe`

**Запуск через скрипт:** `.\run.bat`

**Запуск без отдельной сборки:** `go run ./src`

**Запуск тестов:** `go test ./...`

**Запуск с параметрами:** `.\run.bat -vfs "data/vfs.csv" -script "tests/startup_ok.txt"`

**Проверка параметров запуска:** `.\tests\check_parameters.bat`

Скрипт проверяет параметры -vfs и -script по отдельности и совместно.

**Проверка ошибочных сценариев:** `.\tests\check_errors.bat`

Скрипт проверяет неизвестную команду, отсутствие стартового скрипта и незакрытые кавычки.
В этих сценариях ожидается ненулевой код завершения эмулятора.

**Проверка вариантов VFS:** `.\tests\check_vfs.bat`

Скрипт запускает эмулятор с тремя вариантами VFS и стартовым скриптом
`tests/startup_vfs.txt`. Проверяются заглушки ls и cd с разными аргументами,
обработка кавычек и завершение по exit.

**Проверка ошибочных сценариев с VFS:** `.\tests\check_vfs_errors.bat`

Для каждого из трёх вариантов VFS проверяются неизвестная команда,
незакрытые кавычки и аргументы у exit.
Дополнительно проверяются отсутствие CSV-файла и неверное содержимое Base64.
В ошибочных сценариях ожидается ненулевой код завершения эмулятора.

Тесты Go проверяют разбор команд, загрузку корректных и некорректных VFS,
двоичные данные и неизменность исходного CSV-файла.

## Примеры использования.
Пример 1 *(username и hostname заменяются реальными данными ОС)*:

```text
username@hostname:~$ ls -l "my folder"
ls: аргументы ["-l" "my folder"]
username@hostname:~$ cd 'моя папка'
cd: аргументы ["моя папка"]
username@hostname:~$ unknown
Ошибка команды: неизвестная команда: unknown
username@hostname:~$ cd "folder
Ошибка разбора: незакрытые кавычки
username@hostname:~$ ls ""
ls: аргументы [""]
username@hostname:~$ exit x
Ошибка команды: exit не принимает аргументы
username@hostname:~$ exit
```

Пример 2 — успешное выполнение стартового скрипта:

```powershell
go run ./src -script "tests/startup_ok.txt"
```

Программа автоматически выполняет ls, cd с аргументом "my folder",
ls с пустым аргументом и exit.
На экране отображаются команды и результаты.

Пример 3 — остановка стартового скрипта при ошибке:

```powershell
go run ./src -script "tests/startup_error.txt"
```

После выполнения ls обнаруживается неизвестная команда на второй строке:

```text
Ошибка выполнения: строка 2: неизвестная команда: unknown
```

Следующая команда cd не выполняется.

Пример 4 — загрузка VFS с вложенными каталогами:

```powershell
go run ./src -vfs "data/nested.csv" -script "tests/startup_vfs.txt"
```

После загрузки выводится `Элементов VFS: 7`.
Затем выполняются команды стартового скрипта.
Команда после exit не выполняется.

Пример 5 — отсутствующий файл VFS:

```powershell
go run ./src -vfs "data/not_found.csv" -script "tests/startup_vfs.txt"
```

Программа сообщает об ошибке открытия VFS и завершается с ненулевым кодом.
Стартовый скрипт не выполняется.

Пример 6 — неверное содержимое Base64:

```powershell
go run ./src -vfs "tests/invalid_vfs.csv" -script "tests/startup_vfs.txt"
```

Программа сообщает об ошибке Base64 в третьей записи CSV
и завершается с ненулевым кодом. Стартовый скрипт не выполняется.
